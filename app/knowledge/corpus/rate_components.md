# 运价构成与附加费

## 运价的基本构成

海运费报价由以下部分构成，缺一不可：

- 基本海运费（Ocean Freight）：按箱型计收，是报价主体。
- 起运港费用（Origin Charges）：订舱费、文件费、码头操作费（THC）。
- 目的港费用（Destination Charges）：码头操作费、拆箱费、文件费。
- 附加费（Surcharges）：随市场与政策变动，名目繁多。

## 常见附加费

- 燃油附加费（BAF / LSS）：随油价浮动，按月或按季调整。
- 旺季附加费（PSS）：旺季临时加收，通常提前公布生效期。
- 综合费率上涨附加费（GRI）：船公司统一调价，按公告执行。
- 低硫燃油附加费（LSS）：与环保法规相关，独立于 BAF。
- 超重附加费：单箱超过限重时加收。
- 危品附加费、冷藏附加费：按货物属性加收。

## 报价口径

对客户报价时须明确：

1. 报价是否为全包价（All-in），若为全包须列明包含的附加费项目。
2. 有效期（Validity）：海运费随市场波动，报价必须标注有效期。
3. 汇率基准：以外币报价时须注明汇率与调整机制。
4. 费用承担方：按贸易条款（FOB / CIF / EXW）划分起运港与目的港费用。

## 报价纪律

- 不得以低于成本加最低利润的价格报价，最低利润由定价规则统一设定。
- 报价一经确认，在有效期内不得单方面上调。
- 附加费在报价有效期后调整的，须重新出具报价单，不得口头通知。

## 与客户沟通要点

客户询问"为什么这个月贵了"时，应先拆分基本运费与附加费的变化，
再说明触发原因（旺季、油价、航线调整），避免笼统归因于市场行情。
