国际货代多智能体平台 — 演示入口

一条询价从解析到订舱的完整链路，加上四个可以单独验证的能力面。 每个页面只演示一件事，并且都对着真实接口跑——没有一段是写死的截图。
01 · 业务流程

业务闭环

询价解析 → 船期 → 运价 → RFQ → 比价 → 人工放行 → 报价 → 订舱 → 船位跟踪。 线性推进，走到人工闸门会主动停下。

需要：演示询价（页面内可一键创建）
02 · 编排引擎

图编排控制台

11 个节点的 LangGraph 状态图：四个条件分支，停在哪个节点就从哪个节点续跑。 包含「缺字段追问」「报价不足等待」「人工闸门」三种真实交互。

需要：一张询价单（页面内可新建）
03 · 知识能力

知识台

SOP 检索作答（带引用）、域外问题明确拒答、只读工具调用轨迹、运行延迟与成本度量。 拒答在这里是一等结果，不是错误。

需要：SOP 语料（页面内可一键灌入）
04 · 增长

主动获客

从公开信息找潜客 → 富化 → 合规复核 → 草拟触达 → 人工审阅后发送。 未核实的线索与 CRM 物理隔离。

需要：演示潜客（合成数据，带 mock_synthetic 标记）

第一次跑？

1. python scripts/bootstrap_dev.py —— 建 venv、装依赖、用 alembic 建表、灌演示数据与 SOP 语料。
2. uvicorn app.main:app --reload --port 8100
3. 打开 http://localhost:8100/demo/，或直接看 API 文档。
应用启动时会校验数据库是否在 alembic head：不在就拒绝启动并给出修复命令， 而不是带着旧 schema 起来再在某个接口上 500。
金额、权限、状态迁移、审批、发送全部由确定性代码控制，模型只负责理解与措辞。 演示使用 AUTH_MODE=dev 请求头鉴权，不可用于生产。
